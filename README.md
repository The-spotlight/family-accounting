# 家庭收支记账系统

## 🛠 技术栈
- Frontend: Vue 3 + Vite + Element Plus + Pinia + Axios + Sass

## 🚀 启动指南 (How to Run)
1. 确保 Docker Desktop 已启动。
2. 在根目录执行：`docker compose up --build`
3. 等待容器启动完成...
4. 访问：http://localhost:3000

## 🔗 服务地址 (Services)
- Frontend: http://localhost:3000

## 📝 功能说明
- **登录页面**：用户登录认证
- **首页**：收支统计概览（总收入、总支出、余额、收支笔数）
- **明细页面**：收支记录列表和管理（支持添加、编辑、删除、筛选）
